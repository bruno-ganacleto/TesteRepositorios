Sistema Monolítico de Cadastro de Motores em Python

Prototipagem de lógica de programação e manipulação de estruturas de dados em memória, desenvolvida durante a formação técnica no CentroWEG (SENAI).

Sobre o Projeto

Este software foi criado com foco em testes rápidos de lógica de programação, aplicando o conceito de CRUD (Criar, Ler, Atualizar e Deletar) sem dependência de bancos de dados externos. Todo o fluxo ocorre em um único arquivo Python, utilizando listas (arrays) e dicionários para armazenar dados técnicos de motores em tempo de execução.

Como o Código Funciona

01. Armazenamento

Lista & Dicionários

A variável global motores = [] atua como um array dinâmico. Cada motor cadastrado é armazenado como um dicionário contendo id, modelo, fabricante, tipo e potencia_cv.

02. Modularização

Funções Dedicadas

Cada operação do sistema possui sua própria função: cadastrar_motor(), listar_motores(), atualizar_motor() e remover_motor(), facilitando a leitura e manutenção.

03. Validação

Tratamento de Erros

Blocos try/except garantem que entradas inválidas (como texto no lugar de potência em CV ou IDs inexistentes) não interrompam a execução do programa.

04. Interface CLI

Menu Interativo

A função menu() mantém um laço contínuo while True no terminal até que o usuário selecione a opção 0 para encerrar a sessão.

Código-Fonte (cadastro_motores.py)

Implementação monolítica completa utilizada para validação em terminal:

cadastro_motores.py 
# Lista global (array) para armazenar os motores em memória
motores = []
proximo_id = 1

def cadastrar_motor():
    global proximo_id
    print("\n--- CADASTRAR NOVO MOTOR ---")
    modelo = input("Modelo do motor: ").strip()
    fabricante = input("Fabricante: ").strip()
    tipo = input("Tipo (Elétrico, Combustão, Híbrido, etc.): ").strip()
    
    while True:
        try:
            potencia_cv = float(input("Potência (em CV): "))
            break
        except ValueError:
            print("Erro: Digite um valor numérico válido para a potência.")

    motor = {
        "id": proximo_id,
        "modelo": modelo,
        "fabricante": fabricante,
        "tipo": tipo,
        "potencia_cv": potencia_cv
    }
    
    motores.append(motor)
    proximo_id += 1
    print(f"\n[SUCESSO] Motor '{modelo}' cadastrado com ID {motor['id']}!")

def listar_motores():
    print("\n--- LISTA DE MOTORES CADASTRADOS ---")
    if not motores:
        print("Nenhum motor cadastrado no momento.")
        return

    for m in motores:
        print(
            f"ID: {m['id']} | Modelo: {m['modelo']} | "
            f"Fabricante: {m['fabricante']} | Tipo: {m['tipo']} | "
            f"Potência: {m['potencia_cv']} CV"
        )

def buscar_motor_por_id(id_busca):
    for motor in motores:
        if motor["id"] == id_busca:
            return motor
    return None

def atualizar_motor():
    print("\n--- ATUALIZAR MOTOR ---")
    listar_motores()
    if not motores:
        return

    try:
        id_busca = int(input("\nDigite o ID do motor que deseja atualizar: "))
    except ValueError:
        print("Erro: ID inválido.")
        return

    motor = buscar_motor_por_id(id_busca)
    if not motor:
        print("Motor não encontrado.")
        return

    novo_modelo = input(f"Modelo [{motor['modelo']}]: ").strip()
    if novo_modelo: motor["modelo"] = novo_modelo

    novo_fabricante = input(f"Fabricante [{motor['fabricante']}]: ").strip()
    if novo_fabricante: motor["fabricante"] = novo_fabricante

    novo_tipo = input(f"Tipo [{motor['tipo']}]: ").strip()
    if novo_tipo: motor["tipo"] = novo_tipo

    nova_potencia = input(f"Potência CV [{motor['potencia_cv']}]: ").strip()
    if nova_potencia:
        try:
            motor["potencia_cv"] = float(nova_potencia)
        except ValueError:
            print("Potência inválida. Mantendo o valor anterior.")

    print("\n[SUCESSO] Dados do motor atualizados!")

def remover_motor():
    print("\n--- REMOVER MOTOR ---")
    listar_motores()
    if not motores:
        return

    try:
        id_busca = int(input("\nDigite o ID do motor que deseja remover: "))
    except ValueError:
        print("Erro: ID inválido.")
        return

    motor = buscar_motor_por_id(id_busca)
    if not motor:
        print("Motor não encontrado.")
        return

    motores.remove(motor)
    print(f"\n[SUCESSO] Motor '{motor['modelo']}' (ID {id_busca}) removido!")

def menu():
    while True:
        print("\n===============================")
        print("   SISTEMA DE CADASTRO DE MOTORES")
        print("===============================")
        print("1. Cadastrar motor")
        print("2. Listar motores")
        print("3. Atualizar motor")
        print("4. Remover motor")
        print("0. Sair")
        
        opcao = input("\nEscolha uma opção: ").strip()

        if opcao == "1": cadastrar_motor()
        elif opcao == "2": listar_motores()
        elif opcao == "3": atualizar_motor()
        elif opcao == "4": remover_motor()
        elif opcao == "0": break
        else: print("Opção inválida!")

if __name__ == "__main__":
    menu()
